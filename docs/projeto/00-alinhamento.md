# Registro de alinhamento

## Ponto de partida

O [README](../../README.md) registra a visão de comparação de aplicações autorizadas e de equivalência por cenários. O repositório está na fase de iniciação. O [plano](../../PLANO-REVENG.md) propõe um piloto local com uma referência própria e dados sintéticos, para validar o fluxo antes de investir na plataforma completa.

## Decisões a registrar

| Questão | Evidência para decidir |
| --- | --- |
| Aplicação de referência e cenários | Contrato revisado com operações, resultados e critérios de aceite |
| Ferramenta dos testes web | Execução reproduzível nas duas implementações e documentação local |
| Formato e retenção da evidência | Exemplo de relatório com versões, observações, resultado e prazo de descarte |
| UI de gestão, API e banco | Necessidades comprovadas de consulta, volume, permissões e concorrência |
| Licença e distribuição | Termos aprovados pelo proprietário |

Cada decisão deve citar o registro ou revisão que a fundamentou. Manter os estados proposta, aceita, rejeitada ou substituída com data e responsável.

## Entregáveis por etapa

1. Iniciação com plano, escopo da referência e critérios de aceite.
2. Planejamento com fixture, contrato e procedimento de reposição de estado.
3. Validação com testes de interface, relatório por execução e reexecução de divergências.
4. Encerramento com aceite, cobertura restante e decisões sobre a próxima etapa.
